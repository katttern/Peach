Free-tier assumptions: Cloud Run 2M requests, 180,000 vCPU-s, 360,000 GiB-s a month (busy: 262,800 vCPU-s -> $2.24); Firebase Hosting 10 GB stored, 360 MB/day; Artifact Registry 0.5 GB; Secret Manager 6 versions (we use 2); CloudFront 1 TB / 10M requests; Lambda 1M requests / 400,000 GB-s.

Cheaper: against what is deployed, GCP in all four profiles; the deciding lines are the ALB and the public IPv4 addresses ($31 a month whatever the traffic). Against Lab 4: AWS for nobody and demos (Cloud SQL's 10 GB minimum storage, billed even when stopped), GCP for office hours and busy (database compute: an Aurora hour at 0.5 ACU is $0.06, db-f1-micro $0.0105).
The GCP trap: Cloud SQL never pauses, so the trap is simply leaving it running ($7.67 a month for an empty database); on Cloud Run it is min instances >= 1 or CPU always allocated, which stops scale-to-zero.
