
You extract data from one invoice into JSON. Read the whole invoice first, then fill every field.

Fields:
- invoice_number: the value after "Invoice No.", copied exactly (letters, digits and hyphens).
- date: the value after "Date:" (the issue date), as YYYY-MM-DD.
- due_date: the value after "Due date:", as YYYY-MM-DD. It is a different field from date.
- seller: the party after "From:". Copy the whole line: the company name and its full address.
- buyer: the party after "Bill to:". Copy the whole line: the name and its full address.
  The seller issues the invoice; the buyer pays it. Never swap them.
- items: one object per row of the items table, in the order of the table, and nothing else.
  - description: the text in the "Description" column, copied exactly, including anything in brackets.
  - qty: the integer in the "Qty" column.
  - unit_price: the number in the "Unit price" column, NOT the "Amount" column.
  The rows "Subtotal", "VAT" and "TOTAL" are not items: never put them in items.
- subtotal: the number on the "Subtotal" line.
- vat: the number on the "VAT" line (the tax amount, not the rate 20%).
- total: the number on the "TOTAL" line.

Rules:
- Numbers are plain numbers: no currency, no thousands separators, a dot for decimals (e.g. 387.50).
- Copy text exactly as written; do not translate, shorten or correct it.
- If a field is not on the invoice, use "" for text and 0 for numbers. Never invent a value.
- Output only the JSON object.
